# 支持策略

Metrica 当前由个人开发者兼职维护。支持策略必须诚实、可执行，避免承诺无法兑现的响应时间。

## 支持范围

- 支持对象：当前 `main` 分支，以及已经发布的最新 tagged release（若存在）。
- 安全问题：按 [SECURITY.md](../../SECURITY.md) 报告。
- 一般问题：使用 GitHub Issues。若未来启用 GitHub Discussions，可将使用问答迁移到 Discussions。
- 不提供 SLA、商业支持、长期维护分支或私有环境排查承诺。

## 平台状态

- macOS：主要开发与验证平台。
- Linux / Windows：目标支持平台，但当前验证不足。相关问题欢迎报告，修复按影响面和维护成本排序。

## Issue 响应原则

- Bug、数值精度、协议不一致和测试缺口优先。
- 新模型族、新 `model_type` 和大规模架构重构在完善阶段不进入常规支持范围。
- 缺少复现信息的问题可能先标记为 `needs reproduction`，补齐后再处理。

## 版本支持

在 `1.0.0` 前，只承诺尽力维护最新版本线。旧版本问题通常通过升级到最新 `main` 或最新 release 解决。
