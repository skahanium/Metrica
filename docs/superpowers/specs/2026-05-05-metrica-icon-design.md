# Metrica 图标设计规格

> **状态：已实现。** 已完成 SVG 源文件和全部 PNG 尺寸导出。

## 概述

Metrica 品牌图标，用于桌面应用、网站/favicon、文档/README 标题图等全用途场景。

## 设计目标

1. **现代感**：体现现代计量经济学工具的专业性
2. **辨识度**：在众多工具中具有独特识别性
3. **教学友好**：符合 Metrica 教学友好的产品理念
4. **多场景适配**：支持从 16x16 到 512x512 的多种尺寸

## 设计规格

### 核心符号

**折线 M + 数据节点**

- 一条连续折线形成抽象的 "M" 形态，同时暗示回归趋势线
- 三个圆形数据节点位于折线的转折点，暗示统计散点分布
- 设计风格：极简线条、抽象几何
- 双重含义：Metrica 首字母 + 统计回归分析

### 外框形状

**实心圆角方形 (Squircle)**

- 比例：1:1 正方形
- 圆角半径：21%（相对于边长，viewBox 160 中 rx=34）
- 全填满底色，标准应用图标风格

### 配色方案

| 元素 | 色值 | 用途 |
|------|------|------|
| `#1e293b` | slate-800 | 外框底色 |
| `#f1f5f9` | slate-50 | M 折线主线条 |
| `#94a3b8` | slate-400 | 数据节点圆点 |

### 尺寸规格

| 尺寸 | 用途 |
|------|------|
| 16×16 px | favicon、小图标 |
| 32×32 px | 工具栏图标 |
| 64×64 px | 中等图标 |
| 128×128 px | 应用图标 |
| 256×256 px | 高分辨率图标 |
| 512×512 px | 应用商店、文档标题图 |

### 输出格式

- SVG：矢量源文件，可缩放至任意尺寸
- PNG：各位图尺寸导出

## 设计原则

1. **简洁性**：极简线条 + 三节点，小尺寸下仍清晰可辨
2. **一致性**：全系列同一配色和比例
3. **可扩展性**：SVG 矢量格式支持任意缩放
4. **专业性**：暗色底配浅色线条，工具类应用气质
