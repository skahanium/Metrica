# Metrica 图标设计规格

> **状态：已创建，待视觉验证。** 本文件是新创建的设计规格文档，用于记录 Metrica 项目图标的视觉设计规格。图标已导出多种尺寸，但验收标准中的视觉检查项（如 16x16 清晰度、深浅背景表现）尚未经过实际验证。

## 概述

本设计文档定义 Metrica 项目的品牌图标规格，用于桌面应用、网站/favicon、文档/README 标题图等全用途场景。

## 设计目标

1. **现代感**：体现现代计量经济学工具的专业性
2. **辨识度**：在众多工具中具有独特识别性
3. **教学友好**：符合 Metrica 教学友好的产品理念
4. **多场景适配**：支持从 16x16 到 512x512 的多种尺寸

## 设计规格

### 核心符号

**σ（标准差符号）**

- 选择理由：σ 是统计学与计量经济学的核心符号，代表标准差与不确定性量化
- 设计风格：几何化重构，用直线和圆弧重新构建 σ 形态
- 视觉特征：简洁、现代、专业

### 外框形状

**圆角方形**

- 比例：1:1 正方形
- 圆角半径：约 12%（相对于边长）
- 视觉效果：友好、现代、易于识别

### 配色方案

**主色调**

- 石板灰：`#4a5568`（用于外框与符号）
- 深灰：`#2d3748`（用于深色背景场景）

**辅助色**

- 白色：`#f7fafc`（用于符号内部与反白场景）
- 浅灰：`#718096`（用于辅助元素）

### 尺寸规格

**标准尺寸**

- 16x16 px：favicon、小图标
- 32x32 px：工具栏图标
- 64x64 px：中等图标
- 128x128 px：应用图标
- 256x256 px：高分辨率图标
- 512x512 px：应用商店、文档标题图

**输出格式**

- SVG：矢量格式，用于缩放与编辑
- PNG：位图格式，用于各尺寸导出
- ICO：Windows 图标格式（如需要）
- ICNS：macOS 图标格式（如需要）

## 设计含义

### 符号含义

- **σ 符号**：代表标准差，体现统计与不确定性量化能力
- **几何化设计**：体现现代感与专业性
- **圆角方形**：友好、现代、易于识别

### 品牌关联

- **Metrica**：项目名称来源于"metric"（度量）与"measurement"（测量）
- **σ 符号**：直接关联计量经济学的核心统计概念
- **石板灰配色**：中性、专业，适合工具类应用

## 应用场景

### 桌面应用

- 应用图标（macOS、Windows、Linux）
- 窗口标题栏图标
- 任务栏/dock 图标

### 网站与文档

- favicon（16x16、32x32）
- README 标题图
- 文档封面图

### 品牌材料

- 名片
- 演示文稿
- 社交媒体头像

## 设计原则

1. **简洁性**：避免过多细节，确保小尺寸清晰可辨
2. **一致性**：在不同尺寸下保持视觉一致性
3. **可扩展性**：支持从极小到极大的尺寸范围
4. **专业性**：体现计量经济学工具的专业气质

## 非目标

- 复杂的渐变效果
- 过多的细节元素
- 与特定操作系统风格绑定
- 动态或交互式图标

## 验收标准

1. 在 16x16 尺寸下仍可清晰识别 σ 符号
2. 在不同背景色（浅色/深色）下均有良好表现
3. SVG 源文件可正确缩放至任意尺寸
4. 各尺寸 PNG 导出清晰无锯齿
5. 符合 Metrica 品牌调性
