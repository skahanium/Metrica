# `S1` 施工指引：协议与工作台地基

> **状态：已完成。** `S1` 对应的旧 `M1-M5` 已完成收口；本文件保留为阶段边界与验收口径记录。

## 阶段目标

`S1` 的目标是把 `Core -> Runtime -> App -> Output` 的稳定主链路做成可靠底座，为后续模型扩张提供统一协议、统一结果语义与可持续工作台结构。

## 纳入能力

- `MetricaBase.jl` 协议内核、统一结果语义、错误/警告码体系
- Runtime 的结构化请求/响应、任务状态、取消与日志基础
- App 的数据导入、数据检查、基础操作、结果展示主工作流
- 已完成的 OLS/WLS、基础诊断、基础面板、数据操作地基

## 明确排除项

- 不在本阶段追求广泛模型覆盖率
- 不引入开放脚本系统、插件市场或云协作能力
- 不把高级研究专题和 AI 助手当作本阶段验收条件

## 历史映射

- 覆盖旧 `M1-M5`
- 当前主设计 `docs/superpowers/specs/2026-04-30-metrica-main-design.md` 仍作为本阶段的当前实现锚点

## 阶段验收

- 协议、Runtime、App 与输出层之间不依赖文本 summary 解析
- 用户能完成“加载数据 -> 检查数据 -> 基础处理 -> 拟合基础模型 -> 查看结构化结果”的主闭环
- 基础模型与数据能力具备稳定测试门禁与可复用结构
