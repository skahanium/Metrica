# `S2` 施工指引：核心实证工作台

> **状态：已完成。** `S2` 对应的旧 `M6-M7` 已完成收口；本文件保留为阶段边界与验收口径记录。

## 阶段目标

`S2` 的目标是覆盖最常用、最必要、最能支撑教学与常规论文的线性与面板能力闭环，使 Metrica 成为真正可用的核心实证工作台。

## 纳入能力

- OLS/WLS 成熟化、统一 `fit/predict`
- IV/2SLS、GLS/FGLS、稳健/cluster 协方差
- HDFE、CRE、Panel IV、面板诊断升级
- 多模型比较、黄金样例、教学数据集收口

## 明确排除项

- 不在本阶段展开一般 GMM、动态面板、多方程系统等更高复杂专题
- 不以命令覆盖率为目标复制 Stata 工作流
- 不扩大为完整报告产品或项目管理系统

## 历史映射

- 对应旧 `M6-M7`
- 当前活跃文档：`2026-05-03-milestone-6-linear-models-design.md`、`2026-05-03-milestone-7-panel-models-design.md`

## 阶段验收

- 线性与面板核心模型具备统一结构化结果和一致 API
- 关键模型有黄金样例、教学数据集与稳定诊断语义
- App 能用结构化配置和结果展示支撑常见线性/面板实证流程
