# `S5` 施工指引：高级研究专题

## 阶段目标

`S5` 的目标是承载必要性次于 `S4`、但对长期竞争力重要的高复杂专题，并以更克制的节奏扩展研究前沿能力。

## 纳入能力

- 一般 GMM 与过识别检验体系
- 动态面板（Arellano-Bond / System GMM）
- SUR / 联立方程
- 分位数回归
- 非线性 / 门限回归
- 非参数 / 半参数
- ARCH/GARCH、空间、久期、贝叶斯

## 明确排除项

- 不把本阶段内容前移为基础工作台门禁
- 不在协议、项目谱系与输出系统不稳定时仓促接入
- 不用单一教材目录替代产品优先级判断

## 历史映射

- 对应旧路线中尚未正式编排的 `M14+` 空白区

## 阶段验收

- 每个专题进入前都能说明其结构化结果边界与最小垂直切片
- 新专题不会破坏 `S1-S4` 已建立的协议、工作流与输出一致性
- 高复杂模型具备明确的非目标、数据条件与教学说明
