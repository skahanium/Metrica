## S3《复现与报告产品化》

依据：`docs/roadmap/s3-reproducibility-and-reporting.md`

### 纳入能力（原文第 9–16 行）

| 条目 | 判定 | 代码事实（简要） |
|------|------|------------------|
| 项目文件、运行记录、数据谱系、结果复现 | **部分** | **Runtime 层完备：** `server.rs` 提供 `save_project_handler` / `load_project_handler` / `list_runs_handler` / `rerun_task_handler` 与 `persist_run_record`；`vertical_slice.rs` 含 `save_and_load_project_roundtrip`、`fit_model_generates_run_record_and_list_runs_returns_it`、`rerun_task_returns_error_for_missing_dataset` 等集成测例。**App 层部分接通：** `commandExecutor.ts` 实现 `handleSave`、`handleProject`（`open`/`close`/`new`）；`runtimeClient.ts` 有完整的 `rerunTask`、`listRuns`、`loadProject`、`exportReport` 封装。**断裂点：** ① `handleSave` 硬编码 `data_lineage: null`，未读取 `projectStore` 中已由 `dataOperationExecutor.ts` → `appendLineageOperations` 写入的内存谱系；② `App.tsx` 的 `executeCommand` 路由表无 `rerun`/`load`/`runs`/`export` 分支（`commandGrammar.ts` 已定义这些动词语法），用户输入会 fallthrough 到 `handleModel` 被误处理。 |
| 单模型完整报告（Markdown） | **部分** | **Julia 层：** `MetricaOutput.markdown_run_report` 完整实现。**Runtime 层：** `server.rs` 有 `export_report_handler`，`julia_bridge_entry.jl` 有 `export_report` 分支。**测试：** `vertical_slice.rs` 的 `export_report_markdown_returns_content` 验证输出含 `# Metrica 单次运行报告`。**App 层：** `runtimeClient.ts` 有 `exportReport` 封装；但 `App.tsx` 无 `export` 路由分支，CLI 不可达。 |
| 多模型对比表（手动选择，含数据兼容性检查） | **部分** | **Core 层有基础能力：** `MetricaDiscrete.jl/src/model_selection.jl` 有 `ModelComparison` 结构体与 `compare_aic_bic` 函数（按 AIC/BIC 排序多模型）；`MetricaCausal.jl` 有 `compare_estimates` 函数（多因果估计汇总 `TreatmentEffectSummary`）。**缺失：** 无 Runtime 端点、无 App 组件、无 CLI 动词将 Core 层能力暴露给用户。路线图要求的「手动选择 + 数据兼容性检查 + 不兼容拒绝」完全未实现。 |
| 结构化 CSV 导出（tidy / glance / diagnostics） | **部分** | **Julia 层：** `MetricaOutput` 导出 `csv_tidy`/`csv_glance`/`csv_diagnostics`。**Runtime 层：** `export_report_handler` 支持 `csv_tidy`/`csv_glance`/`csv_diagnostics` 格式。**测试：** `vertical_slice.rs` 有 `export_report_csv_tidy_returns_csv`，验证 CSV 含 `term,estimate,std_error,statistic,p_value`。**App 层：** `runtimeClient.ts` 有 `exportReport` 封装（含 `csv_tidy` 等类型）；`App.tsx` 无 `export` 路由，CLI 不可达。 |
| 出版级图表导出（SVG + PNG） | **未见** | `exportStore.ts` 有 `downloadDataUrl` 工具函数，但 `src-react` 中无任何 SVG/PNG 相关代码。`DataFullscreen.tsx` 引用 `downloadText` 仅用于 CSV 数据导出。`EventStudyPlot.tsx` 使用 ECharts 渲染图表，无导出为图片的逻辑。无组件调用 `downloadDataUrl`。 |
| 错误恢复（Julia 崩溃后恢复工作区状态） | **部分** | **进程级恢复已实现：** `julia_session.rs` 有 `check_alive` / `mark_unhealthy` / `try_restart`（`MAX_RESTARTS = 3`）；`healthPolling.ts` 每 1–30 秒轮询健康状态。`App.tsx` 有分级 UI 提示（重启中 / 已达上限）。**工作区状态恢复未实现：** 崩溃后仅恢复 Julia 进程，UI 中已打开的数据集、模型结果、项目上下文不会自动恢复，与路线图「工作区状态级恢复」不等价。 |

依据：`docs/roadmap/s4-high-frequency-applied-models.md`

### 纳入能力（原文第 7–12 行）

| 条目 | 判定 | 代码事实（简要） |

| GLM / 有限因变量：Logit、Probit、Poisson、边际效应等 | **已满足** | `MetricaDiscrete.jl` 导出 `LogitModel`/`ProbitModel`/`PoissonModel`/`OrderedLogitModel`/`MultinomialLogitModel`/`NegBinModel`，含完整 IRLS 实现、边际效应（`ame`/`mem`）、模型选择（`lr_test`/`compare_aic_bic`）。`julia_bridge_entry.jl` 经 `MODEL_REGISTRY` 派发。`commandGrammar.ts` 含 `logit`/`probit`/`poisson`/`ologit`/`mlogit`/`nbreg`/`margins`。`runtimeClient.ts` 有完整离散模型类型分支。App 有 `DiscreteGlanceCards`/`OddsRatioTable` 展示组件。 |

| 复杂抽样：pweights、strata、PSU、survey-aware regression | **已满足** | `MetricaSurvey.jl` 有 `SurveyDesign`（含 `weights_column`/`strata_column`/`psu_column`/`fpc_column`）、四种 `Survey*Model`/`Survey*FitResult`、`DEFFResult`，以及 `design_effect`/`strata_summary`。`julia_bridge_entry.jl` 有完整 survey 分支。CLI 有 `svy` 前缀。App 有 `SurveyDesignPanel`/`StrataSummary`/`DEFFSummary` 展示组件。 |
