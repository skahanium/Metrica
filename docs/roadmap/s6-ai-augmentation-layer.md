# `S6` 施工指引：AI 增强与研究助理层

## 阶段目标

`S6` 的目标是在前述阶段的结构化对象足够稳定后，引入受控 AI 助手能力，用于解释、建议与复现协助，而不是开放任意脚本执行。

## 纳入能力

- 基于 `RunRecord`、`DataLineage`、`DiagnosticFinding`、`ModelComparison` 的解释与建议
- 教学解释、报告草稿、下一步分析建议
- 受控动作预览与确认

## 明确排除项

- 不开放任意 Julia / shell / SQL / Python 脚本执行入口
- 不让 AI 解析文本 summary 作为事实来源
- 不让 AI 自动改写数据或模型，除非用户明确确认结构化动作

## 历史映射

- 对应旧 `M20`
- 旧 `M20` 只作为历史编号保留，不再作为独立长期阶段名称

## 阶段验收

- 每条建议都能追溯到结构化数据、模型结果或诊断对象
- 每个会改变项目状态的动作都能预览、确认、撤销或重跑
- AI 增强教学与复现能力，而不是替代用户理解计量方法
