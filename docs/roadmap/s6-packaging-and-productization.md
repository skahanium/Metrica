# `S6` 施工指引：安装包与产品化收口

> **从 S3 拆出。** 原 S3 范围过大，安装包与产品化收口独立为一个阶段，聚焦桌面端打包、错误恢复与课堂示例工程。

## 阶段目标

`S6` 的目标是将 Metrica 桌面端从"开发者可运行"提升为"终端用户可安装、可恢复、可演示"，完成产品化的最后一公里。

## 纳入能力

- 可安装制品：安装包 / 签名 / 自动更新策略等（**当前 Alpha 为 tao+wry 外壳**；具体打包技术栈如 Tauri、electron-builder 或其他方案在本阶段评估选定，产出 macOS / Windows / Linux 可分发格式）
- Julia 运行时捆绑或自动安装机制
- Julia 崩溃后的自动恢复与用户提示
- 最近项目管理的完整产品化
- 最小课堂/示例工程（预置数据集 + 预置模型 + 一键演示）
- 应用图标、启动画面、版本号管理

## 明确排除项

- 不在本阶段增加新模型族或新导出格式
- 不做云同步、多用户能力
- **自动更新**不作为本阶段必交付项（若纳入仅做方案与开关设计，不强制上线）
- 不做插件市场或扩展系统

## 阶段验收

- macOS / Windows 可产出可安装的桌面应用包
- 应用首次启动时能自动检测并配置 Julia 环境
- Julia 崩溃后应用可自动恢复到上次工作状态
- 课堂演示可通过预置工程一键启动
- 应用具备基本的产品级外观（图标、启动画面、版本号）
