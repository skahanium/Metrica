# `S6` 施工指引：安装包与产品化收口

> **从 S3 拆出。** 原 S3 范围过大，安装包与产品化收口独立为一个阶段，聚焦桌面端打包、错误恢复与课堂示例工程。

## 阶段目标

`S6` 的目标是将 Metrica 桌面端从"开发者可运行"提升为"终端用户可安装、可恢复、可演示"，完成产品化的最后一公里。

## 纳入能力

- Tauri 打包配置（macOS .dmg / Windows .msi / Linux .AppImage）
- Julia 运行时捆绑或自动安装机制
- Julia 崩溃后的自动恢复与用户提示
- 最近项目管理的完整产品化
- 最小课堂/示例工程（预置数据集 + 预置模型 + 一键演示）
- 应用图标、启动画面、版本号管理

## 明确排除项

- 不在本阶段增加新模型族或新导出格式
- 不做云同步、自动更新或多用户能力
- 不做插件市场或扩展系统

## 阶段验收

- macOS / Windows 可产出可安装的桌面应用包
- 应用首次启动时能自动检测并配置 Julia 环境
- Julia 崩溃后应用可自动恢复到上次工作状态
- 课堂演示可通过预置工程一键启动
- 应用具备基本的产品级外观（图标、启动画面、版本号）
